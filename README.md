Student Result Analyzer

1. Project Introduction

Student Result Analyzer is a C programming project designed to manage student academic records and analyze examination results.

2. Project Objectives

- Store student details.
- Calculate total marks and percentage.
- Assign grades to students.
- Check PASS or FAIL status.
- Find class topper.
- Calculate class and subject averages.

3. Features

1. Display All Students
2. Search Student by Roll Number
3. Find Class Topper
4. Calculate Class and Subject Average
5. Find Subject-wise Topper

4. Technologies Used

- Programming Language: C
- Header Files: stdio.h, string.h
- Data Structure: Structure and Arrays
- Functions: User-defined Functions

5. Project Details

- Maximum Students: 50
- Number of Subjects: 5
- Maximum Marks: 500
- Passing Marks: 40 per subject

6. Grading System

- 90% and above: Grade A
- 75% to 89%: Grade B
- 60% to 74%: Grade C
- 50% to 59%: Grade D
- Below 50%: Grade E
- Failed in any subject: Grade F
